
Uses API to signal Emby to scan library for changes
To use, navigate to http://myembyserver:8096/web/index.html#!/apikeys.html and generate a new API Key 

This work/it's author is separate from and not affiliated with the Emby Project, https://jellyfin.org/.

## !!!IMPORTANT NOTICE!!!
### In order for library scans to work when using containers (i.e. Docker) the mount paths to your media files MUST be the same (i.e. if your media library is mounted as /mymedia on Emby, your media library must be mounted as /mymedia on Unmanic)
